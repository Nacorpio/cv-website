# CV Website

## Purpose
A personal CV website that presents my skills, education and projects to potential employers and to developers who want to collaborate. It is also my Module 2 project at Lexicon (HTML and CSS only).

Live site: https://nacorpio.github.io/cv-website/

## Features
- Sections for About Me, Skills, Education, Projects and Contact
- Navigation bar that links to each section
- Links to my GitHub and LinkedIn in the Contact section
- Styling built on CSS variables (theme still in progress)
- Responsive layout (partly finished)

**Planned:** dark mode as part of the theme, a downloadable CV, and finishing the responsive layout.

## Technologies
- HTML5 (semantic elements)
- CSS3 (variables, flexbox, media queries)
- Git and GitHub, with GitHub Pages for hosting
- VS Code
- AI assistants (Claude Code, GitHub Copilot) for guidance and review

## How to run
1. Clone the repository: `git clone https://github.com/Nacorpio/cv-website.git`
2. Open `index.html` in a browser.

No build step or dependencies are needed.

## Deployment
The site is hosted on GitHub Pages from the `main` branch (root folder). Each push to `main` updates the live site after about a minute.

## Project structure
```
index.html   page content
style.css    styles
script.js    optional JavaScript (not used yet)
images/      pictures
files/       downloadable files (e.g. a CV PDF)
```
